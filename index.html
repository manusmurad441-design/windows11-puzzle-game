Mission: free Windows 11 from a broken build

You're a new developer at Microsoft. While building Windows 11, the engineer in charge of the file system vanished, leaving the build stuck mid-way. Solve 3 puzzles to fix the system and ship it to the world.

Puzzle 1: Put the boot sequence in the correct order.

Puzzle 2: Complete the sequence (hint: powers of 2):
8, 16, 32, 64, ?

Puzzle 3: Match each pair of icons to repair the system files.

System freed. Thanks to you, Microsoft officially shipped Windows 11 to the world. The missing engineer just resurfaced and said thanks for finishing the job.

A simple fan-made puzzle game — not an official Microsoft product
